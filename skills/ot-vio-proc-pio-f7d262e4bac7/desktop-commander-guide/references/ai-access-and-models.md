# AI Access And Models

Use this reference when the user asks about pricing, credits, plans, billing, or which model to use.

## The Credits Plan

Desktop Commander has one plan: the Credits Plan.

Current public framing:

- a monthly AI usage credits bundle: `$20`, `$50`, `$100`, or `$200` per month
- credits cover the cost of running AI models
- users can change their bundle package at any time
- users can cancel at any time
- new accounts include free starting credits to try Desktop Commander before committing

Use simple language:

- "You pick a monthly credits bundle that fits how much you use Desktop Commander."
- "Credits power your messages — more capable models cost a bit more per message."

## DC credits and the DC Router

Use `DC credits` as the primary term.

Mention that in the model switcher this appears as `DC Router`.

Explain simply:

- all AI models are available through the DC Router
- there is nothing to configure: no separate provider accounts, no API keys
- this makes it easy to try different models on different tasks

## Running out of credits

If a user runs out of credits mid-month, they have two options:

- switch to a bigger bundle immediately, or
- wait for their monthly renewal

Their conversations and context are preserved either way.

## Model chooser

Do not present model choice as one permanent answer.

Explain the tradeoffs:

- capability: better for harder reasoning or coding tasks
- speed: faster for quick everyday work
- cost: cheaper models are good for high-volume or lower-stakes tasks

## Current high-level guidance

Available through the DC Router:

- premium options for harder tasks: Anthropic, OpenAI, and Google models
- fast and economical alternatives: `GLM 5.2`, `Mimo 2.5`, and `Kimi`

## Good user-facing guidance

If the user is unsure, suggest:

- start with the smallest bundle and upgrade later if needed
- use a premium model for harder or more important work
- use cheaper models for experimentation or routine tasks
