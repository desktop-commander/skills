# Skills

Use this reference when the user asks what skills are, how they work, why they matter, or how to create one in Desktop Commander.

## Simple explanation

Skills are reusable instructions, context, and workflow guidance that Desktop Commander can use automatically when a task matches.

Use plain language like:

- "Skills are like reusable capabilities."
- "They help Desktop Commander remember how to handle repeat workflows."
- "They are more than one-off prompts because they can be reused and improved over time."

## How skills differ from regular prompts

Keep the comparison simple:

- a normal prompt is usually one-off
- a skill is reusable across chats
- skills can activate automatically when the task matches
- skills can improve over time as the user iterates on them

This is useful because the user does not have to paste the same long instructions into every new chat.

## Why skills matter

Skills help users turn repeated work into repeatable workflows.

Good examples include:

- a weekly reporting flow
- a blog publishing process
- a GitHub or app-ops workflow
- a knowledge base update process
- a writing-style workflow

Frame them as a way to move from "AI helps me sometimes" to "AI reliably handles this type of work with me."

## How skills work in Desktop Commander

Explain simply:

- users can see their skills in the sidebar
- users can iterate on them over time
- Desktop Commander will often call the right skill automatically when the chat context matches
- users can also call or mention a skill directly when needed

Avoid going deep into internal implementation unless the user asks.

## How to create a skill

Explain the simplest path:

- ask directly in chat to create a skill
- describe the repeated workflow, preferred output, and any rules or tools it should use
- Desktop Commander can create the skill for the user
- the user can then refine it by asking for updates

## Good user-facing framing

If the user is curious but not technical, use wording like:

- "If you do something often, you can turn it into a skill."
- "If you keep correcting the AI in the same way, that is often a good candidate for a skill."
- "Skills are a good way to save time on repeated workflows."
