# Troubleshooting And Common Confusions

Use this reference when the user is confused about Desktop Commander, unsure why they should use it, or blocked by common setup and product-understanding issues.

## "What can this actually do?"

Do not answer with a feature dump.

Answer with:

- one-sentence mental model
- a few use cases by goal
- a few concrete tasks they can try right now

## "Why would I use this instead of ChatGPT?"

Use simple language:

- ChatGPT is great for conversation and general help
- Desktop Commander is for doing real work on the user's computer and connected apps
- it is especially useful when the job involves files, folders, code, setup, documents, or multi-step workflows

## "How do credits and billing work?"

Explain simply:

- Desktop Commander has one plan: the Credits Plan
- users pick a monthly credits bundle — `$20`, `$50`, `$100`, or `$200` per month
- credits cover the cost of running AI models through the DC Router
- bundles can be changed at any time, and users can cancel at any time
- new accounts include free starting credits

## "What model should I use?"

Do not overwhelm the user.

Give a short chooser:

- premium for harder tasks: Anthropic, OpenAI, and Google models
- fast and economical for everyday work: GLM 5.2, Mimo 2.5, and Kimi

## "What are Apps or MCPs and do I need them?"

Explain:

- they are app connections
- they are optional
- they are useful when the task crosses tools
- they unlock workflows with services like Notion, GitHub, and Excalidraw

## "What are skills?"

Explain simply:

- skills are reusable instructions and workflow context
- they help Desktop Commander handle repeated tasks more reliably
- they can trigger automatically when the task matches
- users can create one just by asking in chat
- users can see skills in the sidebar and keep improving them

Keep the answer outcome-focused rather than technical.

## "What should I try first?"

Always suggest one small, concrete, trust-building task such as:

- organize one folder
- summarize one file
- explain one project
- connect one app the user already relies on

If the user already has a project or codebase, suggest pointing Desktop Commander at that instead. Users who arrive with an existing project activate the fastest.

## "I ran out of credits mid-task"

Users can switch to a bigger credits bundle at any time, or wait for their monthly renewal. The current conversation and context are preserved. Reassure the user that their work is saved and they can continue once they have credits again.

## "Can I use Desktop Commander in my own language?"

Yes. Desktop Commander works naturally in any language. Many active users work entirely in their own language or switch between languages mid-conversation. There is no need to write in English.

## Tone guidance

Many users are non-technical but curious.

Be encouraging without sounding fluffy. Be clear, practical, and concrete.

Avoid:

- heavy jargon
- assuming the user understands API or model terminology
- abstract product marketing language
