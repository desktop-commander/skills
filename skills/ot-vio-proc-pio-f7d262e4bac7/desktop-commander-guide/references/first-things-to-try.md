# First Things To Try

Use this reference when the user asks what to try first, wants onboarding suggestions, or seems unsure where to start.

## General rule

Recommend tasks that are:

- small
- safe
- visible
- grounded in the user's real files or tools

The goal is to build trust quickly by showing real results on the user's machine.

## For users who already have a project

This is often the fastest activation path. Users who arrive with an existing project folder or codebase tend to get value immediately.

Recommend tasks like:

- point Desktop Commander at your project folder and ask it to explain the structure
- ask Desktop Commander to find and fix a specific bug in your codebase
- ask Desktop Commander to continue building a feature you have been working on
- ask Desktop Commander to create documentation from your existing project files
- paste an error message and ask Desktop Commander to trace and fix the issue

If the user mentions a project, codebase, or app they are building, always start here instead of the generic suggestions.

## Good default starter tasks

Use 3 to 5 suggestions, not a giant list.

Good starter tasks include:

- organize one messy folder such as Downloads or Desktop
- summarize one spreadsheet, CSV, PDF, or export
- explain one project folder or codebase
- create a knowledge base from a folder of documents or notes
- connect one App or MCP such as Notion, GitHub, or Excalidraw

## For non-technical users

Recommend tasks like:

- organize files into clear folders
- rename or sort documents
- summarize PDFs or reports
- clean up a spreadsheet
- create or improve notes and documents
- ask Desktop Commander to check system health and free up disk space
- ask Desktop Commander to help fix a device or peripheral that is not working such as a printer or camera

## For founders, operators, and builders

Recommend tasks like:

- turn a rough idea into a quick prototype
- automate a repetitive file or reporting workflow
- connect GitHub or Notion
- create documentation from project files
- troubleshoot a blocked setup or app workflow

## For developers

Recommend tasks like:

- point Desktop Commander at your app and ask it to fix a specific bug
- ask Desktop Commander to add a new feature by reading your existing code first
- explain a repo
- build a feature from an existing codebase
- generate docs or diagrams from your project structure
- analyze logs or find patterns
- set up or debug a local environment
