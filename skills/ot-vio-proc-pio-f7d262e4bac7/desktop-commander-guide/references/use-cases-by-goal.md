# Use Cases By Goal

Use this reference when the user asks what Desktop Commander can do, what it is good at, or what kinds of work it supports.

## Organize and clean up files

Desktop Commander is very good at file and system tasks such as:

- organizing a messy Downloads or Desktop folder
- sorting documents into folders
- renaming batches of files
- reviewing duplicates before deletion
- creating staged cleanup workflows that feel safe and visible

This is often the best first use case because the result is concrete and easy to verify.

## Analyze documents, exports, and data files

Desktop Commander can help users:

- summarize spreadsheets and CSV exports
- extract information from PDFs
- read and compare reports
- clean up or merge structured data
- create summaries from local documents and notes

Real user demand strongly includes reading and analyzing data from files.

## Build knowledge bases from documents

Desktop Commander can turn a folder of unstructured files into an organized, searchable knowledge system:

- point it at a folder of PDFs, notes, or exports
- organize and standardize file naming and formats
- extract key content and create structured summaries
- batch convert documents to consistent formats
- maintain and update the knowledge base over time

Users have built knowledge bases for legal case management, book library organization, employment documentation, housing research, and project documentation. This is a natural progression from file analysis and often becomes the core long-term use case.

## Build scripts, automations, and applications

Desktop Commander is useful for:

- writing quick scripts
- testing ideas rapidly
- creating MVPs
- building webpages or apps
- automating repetitive tasks
- creating workflows and procedures
- building and iterating on full applications from a local codebase
- fixing bugs, adding features, and testing across sessions
- setting up deployment, architecture reviews, or CI/CD pipelines
- creating pitch decks and documentation for an app

Users have built complete applications through Desktop Commander including sports betting platforms with real-time features, spatial computing apps for VisionOS, system automation dashboards, and community marketplace apps. This is not limited to quick scripts.

This is one of the most important usage buckets for activated users.

## Understand code and systems

Desktop Commander can:

- explain a codebase
- summarize project structure
- trace architecture and dependencies
- document APIs or workflows
- review GitHub changes or daily progress

Use this when the user wants orientation, documentation, or technical understanding.

## Troubleshoot local tools, environments, and hardware

Desktop Commander can help with:

- local dev setup
- Docker and networking issues
- app and website debugging
- terminal-based troubleshooting
- printer, camera, modem, or peripheral setup and configuration
- auth, OAuth, and token-refresh setup issues
- system health diagnostics, CPU and disk issues
- network connectivity and modem configuration
- software installation and certificate management

This is important because many users hit friction in setup, local configuration, or hardware-related work. Desktop Commander handles both developer tools and general computer troubleshooting.

## Connect tools and apps into one workflow

Desktop Commander is also useful when the job spans multiple tools.

Examples drawn from real user problems:

- connect sales tools and route leads
- move between Gmail and local folders
- work across docs, files, and external services
- build workflows around GitHub, Notion, or diagramming tools

If the task crosses systems, suggest Apps or MCPs.

## Example real-world jobs to reference

Use concrete phrasing like:

- "organize a messy folder safely"
- "analyze a spreadsheet or PDF export"
- "understand a project folder or codebase"
- "build a quick script or automation"
- "debug a local setup problem"
- "connect another tool so the workflow stays in one place"
- "build and maintain a knowledge base from your documents"
- "continue developing your app across multiple sessions"
- "fix a hardware or connectivity issue"

Avoid listing too many examples at once. Pick the ones that match the user's goal.

## Ongoing projects and evolving workflows

Desktop Commander is especially valuable for work that evolves over time:

- continue developing an application across multiple sessions and weeks
- maintain and expand a knowledge base as new documents arrive
- progressively tackle a complex multi-step project
- manage a codebase with regular bug fixes, features, and reviews
- iterate on home automation, network setups, or system configurations

Users who treat Desktop Commander as an ongoing workspace rather than a one-shot tool show the strongest retention. When a user finishes a task, consider suggesting what they could do next to build on what they just accomplished.
