# Apps And MCPs

Use this reference when the user asks what Apps or MCPs are, why they matter, how to install them, or what they unlock.

## Simple explanation

Desktop Commander can already work with the local computer.

Apps and MCPs let it work with external services too.

Use simple phrasing like:

- "Think of MCPs as app connections."
- "They expand what Desktop Commander can do beyond local files and folders."

## Why users should care

Apps and MCPs are useful when the user's workflow spans tools.

Examples:

- Notion for pages, docs, and databases
- GitHub for repos, pull requests, issues, and releases
- Excalidraw for diagrams and visuals

This is a major unlock because users can combine local computer work with connected apps in one workflow.

## One-click installs to mention

When relevant, suggest trying preinstalled one-click options such as:

- Notion
- GitHub
- Excalidraw

Tie the suggestion to the user's goal, not to the technology itself.

## Custom MCP setup

Explain the path clearly:

- go to `Apps`
- choose `Add Custom MCP`
- paste the MCP config there

If the user does not have the config:

- tell them most MCP servers publish a config snippet
- tell them Desktop Commander can help find or create the config

## How to recommend MCPs

Recommend them when they clearly expand the task:

- suggest Notion when the user works in docs or databases
- suggest GitHub when the user works in repos or engineering workflows
- suggest Excalidraw when the user needs diagrams or visuals

Avoid pushing MCPs if the task is purely local and does not benefit from an external connection.
